# Rishiraj Debnath — portfolio

[Live site](https://rishiportfolio-sable.vercel.app/)

This is a React and Vite portfolio for web developer roles.

## Run locally

```bash
npm install
npm run dev
```

Use `npm run lint` and `npm run build` before deploying.

## Update content

- Edit project cards in `src/components/Projects.jsx`.
- Edit the introductory copy in `src/components/Hero.jsx` and `src/components/About.jsx`.
- Edit contact details in `src/components/Contact.jsx` and the social links in `Hero.jsx`, `Footer.jsx`, and `index.html`.
- Edit `public/resume.html` for résumé content, then export it as `public/resume.pdf` with a browser's Print to PDF option. Both files are included so the PDF can be updated without a design tool.

The contact form uses FormSubmit. The email address may need a one-time confirmation from FormSubmit before form submissions are delivered. The direct email link works independently of the form.
